FAQ

Common questions.

What is Sentinel Client?

Sentinel is a third party Gorilla Tag utility client controlled from an in game interface. It bundles player information, reporting shortcuts, nametags, friend tools, lobby tools, themes and other convenience features into one mod.

Is Sentinel free?

Yes. There are no Premium or Sentinel+ tiers unlike some money hungry weirdos. The current version is free to download forever and the source is available on GitHub.

Do I need an account or licence key?

No. The website does not have an account page, Discord sign in, licence redemption or paid access system.

Where do I download it?

Use the GitHub release link on this page. That keeps downloads and source history in one place without requiring a website API.

Is Sentinel affiliated with Gorilla Tag?

No. Sentinel Client is a third party project and is not affiliated with Another Axiom or Gorilla Tag. Use mods in accordance with the game’s current rules and policies.

Where do I get support?

Use the Hamburbur Discord , or open an issue on the GitHub repository.
